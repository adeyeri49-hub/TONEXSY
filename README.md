# Forge Games Atelier

A luxury video game store for authentic game keys, prestige physical releases, and collector steelbooks — featuring the animation engine, layout, and visual aesthetics of [Forge Automotive](https://forgeautomotive.co.uk/).

## Features
- **Cinematic Intro Preloader**: Minimalist dark loader with horizontal progress bar and percentage counter.
- **Interactive Cursor Game Trail**: Dropping real game covers with organic tilt and smooth fade-out as the cursor moves over the hero.
- **Ambient Particle Canvas**: Real-time particle constellation mesh with interactive torchlight glow.
- **Conic Glowing Shimmer Buttons**: Spinning conic-gradient borders with 3D character-roll hover interactions.
- **Studio Partner Ticker**: Infinite marquee of premier game publishers (PlayStation, Xbox, Rockstar, FromSoftware, Capcom, EA, Valve, etc.).
- **Sticky Multi-Chapter Pinned Narrative**: Smooth transitions between `01 / 03 Instant Keys`, `02 / 03 Pre-order Vault`, and `03 / 03 Physical Steelbooks`.
- **3-Way Masterpiece Perspective Spread**: "Ordinary Ends Here" spread featuring *Grand Theft Auto VI*, *Elden Ring*, and *Call of Duty BO6* with interactive 3D perspective and parallax spread.
- **Sticky Image Accordion with Clip-Path Wipe**: Vertical wipe transition over 6 game genre categories.
- **Live Games Catalog**: Interactive platform & genre filters, game details modal, and instant "Add to Cart" / "Buy Now".
- **Slide-Over Cart Drawer**: Real-time investment calculation, item removal, and checkout simulation.
- **Fullscreen Navigation**: 3-bar hamburger morph with label flip (`NAVIGATE` ⇄ `CLOSE`).

## Running Locally
Double-click `index.html` in any modern browser, or run:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.
